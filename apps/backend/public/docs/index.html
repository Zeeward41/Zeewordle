Admin

Administrative operations restricted to system administrators, including backend configuration and platform oversight.

Retrieve a list of all registered users.

Returns a paginated list of all users in the system. This endpoint supports filtering, sorting, and is strictly restricted to accounts with administrative privileges.

Authorizations:
SessionAuth
query Parameters
search
string
Example: search=marc

Filter users by name, username, or email (case-insensitive fuzzy match)

page
integer
Default: 1

The page number to retrieve

limit
integer
Default: 20

Number of users per page

Responses

Local development server

http://localhost:8080/v1/admin/users
