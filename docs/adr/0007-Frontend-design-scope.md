# ADR 0007: Frontend Design Scope — Wireframes Only

**Status:** ✅ Accepted  
**Date:** 2026-06-10

## Context
The primary focus of this project is backend development, DevOps, and documentation
practices. A frontend design phase was planned, including wireframes and high-fidelity
mockups using Figma.

Wireframes (mobile and desktop) have been completed and serve as a structural
reference for the UI layout and user flows.

## Decision
High-fidelity mockups will **not** be produced. The effort required to reach
good-quality visual design is disproportionate to the learning objectives
of this project.

The visual design will instead be **inspired by an existing website**, while all
UI components and styles will be implemented manually in CSS — no component
library will be used.

## Consequences

### Pros (+)
- Development can move forward immediately to backend and frontend implementation.
- CSS is written from scratch, keeping full control over the implementation.

### Cons (-)
- No original visual identity for the application.
- The final UI will closely reflect another site's design aesthetic.
