# ADR 0004: Technology Choice for Unit Testing

Status: ✅ Accepted
Date: 2026-05-27

## Context

This project has several objectives, including the adoption of TDD (Test-Driven Development).

## Decision

I have chosen to use vitest for unit testing.

## Consequences

- **Pros (+):** Integrates seamlessly with both the frontend and backend, which already use Vite.
- **Cons (-):** First time implementing unit testing and TDD in a real-world project (learning curve).
